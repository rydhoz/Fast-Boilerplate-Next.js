
# Fast Boilerplate Next.js

A simple and fast boilerplate for building modern web applications with Next.js.

## Packages

### Dependencies

- Next.js 16.2.7
- React 19.2.4
- React DOM 19.2.4
- Tailwind CSS 4
- clsx
- tailwind-merge
- lucide-react

### Development

- TypeScript
- ESLint
- Prettier
- PostCSS
- Autoprefixer
- prettier-plugin-tailwindcss

## Requirements

- Node.js 20+
- npm

## Installation

```bash
git clone <repository-url>

cd Fast-Boilerplate-Next.js

npm install

npm run dev
```

Open http://localhost:3000 in your browser.

## Scripts

```bash
npm run dev
npm run build
npm run start
npm run lint
npm run format
```
